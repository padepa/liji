# 力迹 / Liji

一款专注力量训练过程的 iPhone 记录 App。使用 SwiftUI 和 SwiftData，训练记录保存在设备本地，不需要账号。

这里公开提供免费版 App 的源码，方便学习、审查和非商业改进。App Store 上的版本可能落后于这里；请以商店页面显示的版本和功能为准。

## 功能

- 记录重量、次数、动作时长和组间休息；训练中快速继续下一组或下一个动作。
- 内置三分化、四分化、PPL 等计划及训练模板，也可创建自己的计划和模板。
- 查看训练历史、个人纪录、训练统计和进步复盘。
- 训练提醒、分享海报和多种主题外观。

所有已开放功能都无需订阅。本仓库不包含旧版 Pro 购买页面或订阅管理代码。早期版本的既有订阅仍由 Apple 管理；如需确认续费状态，请查看 Apple ID 的订阅设置。

## 运行

1. 在 Mac 上安装完整 Xcode，并按提示接受 Xcode 许可协议。
2. 打开 `jianshengjily.xcodeproj`，选择 `jianshengjily` scheme 和 iPhone 模拟器后运行。
3. 在真机运行时，请在 Xcode 中选择自己的开发团队，并把 Bundle Identifier 改成自己的唯一标识；不要提交签名文件或私钥。

最低支持 iOS 17。`jianshengjily Watch App` 是保留的实验性 target，不包含在当前 iPhone 商店版本中。肌群图素材与代码也处于未开放的实验状态。

可运行 `./scripts/check_all.sh` 做完整检查；该脚本需要 iOS 和 watchOS Simulator SDK。只检查 iPhone 构建时运行 `./scripts/check_ios_build.sh`。
